# សៀវភៅណែនាំការដំឡើង និងការប្រើប្រាស់ (Installation & Startup Guide)

សៀវភៅណែនាំនេះនឹងជួយអ្នកក្នុងការដំឡើង និងបើកដំណើរការកម្មវិធី **Digital_TTS Studio** នៅលើប្រព័ន្ធប្រតិបត្តិការ Windows និង macOS។

---

## 📋 តម្រូវការប្រព័ន្ធជាមូលដ្ឋាន (System Requirements)
* **Python:** កំណែ 3.12 (តម្រូវឱ្យប្រើប្រាស់ Python 3.12.x ដើម្បីការពារសុវត្ថិភាពកូដ)។
* **ទំហំថាសរឹង (Disk Space):** យ៉ាងហោចណាស់ 5GB ទំនេរ សម្រាប់ផ្ទុកឯកសារម៉ូដែលសំឡេង (Model Weights)។
* **អ៊ីនធឺណិត:** ត្រូវការតែពេលដំឡើងលើកដំបូងដើម្បីទាញយកបណ្ណាល័យកូដ និងម៉ូដែលសំឡេង។ បន្ទាប់ពីនោះ កម្មវិធីអាចដំណើរការបានទាំងស្រុងដោយពុំបាច់មានអ៊ីនធឺណិត (Offline)។

---

## 💻 របៀបដំឡើងនៅលើ Windows (How to Install on Windows)

### ជំហានទី ១៖ ដំឡើង Python
1. ទាញយកកម្មវិធីដំឡើង Python ពីគេហទំព័រផ្លូវការ៖ [https://www.python.org/downloads/](https://www.python.org/downloads/) (ជ្រើសរើសយក Python 3.12.x)។
2. បើកដំណើរការកម្មវិធីដំឡើង ហើយ **ត្រូវតែប្រាកដថាបានធិក (Check) លើប្រអប់ "Add Python to PATH"** នៅផ្នែកខាងក្រោម បន្ទាប់មកទើបចុច "Install Now"។

### ជំហានទី ២៖ ទាញយកប្រភពកូដ និងពន្លាឯកសារ
1. ពន្លា (Extract) ឯកសារហ្ស៊ីប (ZIP) នៃកម្មវិធីនេះទៅក្នុងថតណាមួយនៅលើកុំព្យូទ័ររបស់អ្នក (ឧទាហរណ៍៖ `C:\Digital_TTS`)។

### ជំហានទី ៣៖ ដំឡើងភាពអាស្រ័យ និងម៉ូដែល (Setup)
1. ចូលទៅក្នុងថតកម្មវិធី រួចស្វែងរកឯកសារឈ្មោះ `setup.bat`។
2. ចុចពីរដង (Double-click) លើ `setup.bat` ដើម្បីបើកដំណើរការដំឡើង។
3. កម្មវិធីដំឡើងស្វ័យប្រវត្តិនឹងបង្កើតប្រព័ន្ធនិម្មិត (Virtual Environment), ដំឡើងបណ្ណាល័យកូដទាំងអស់ និងទាញយកម៉ូដែលសំឡេង (Whisper & VoxCPM2) មកទុកក្នុងម៉ាស៊ីន។ ដំណើរការនេះអាចចំណាយពេលពី ៥ ទៅ ១៥ នាទី អាស្រ័យលើល្បឿនអ៊ីនធឺណិតរបស់អ្នក។

### ជំហានទី ៤៖ បើកដំណើរការកម្មវិធី (Start)
1. បន្ទាប់ពីការដំឡើងរួចរាល់ សូមចុចពីរដងលើឯកសារ `START_APP.bat`។
2. ផ្ទាំងបញ្ជា (Terminal) នឹងបើកដំណើរការ ហើយកម្មវិធីរុករក (Web Browser) របស់អ្នកនឹងបើកទៅកាន់គេហទំព័រដោយស្វ័យប្រវត្តិ៖ [http://127.0.0.1:8000](http://127.0.0.1:8000)។

## 🍎 របៀបដំឡើងនៅលើ macOS (How to Install on macOS)

### ជំហានទី ១៖ ដំឡើង Python តាមរយៈ Terminal
1. បើកកម្មវិធី **Terminal** នៅលើ Mac របស់អ្នក។
2. ដំឡើង Python 3 តាមរយៈ Homebrew (ប្រសិនបើមាន)៖
   ```bash
   brew install python@3.10
   ```
   ឬទាញយកកម្មវិធីដំឡើង Mac `.pkg` ពីគេហទំព័រ [python.org](https://www.python.org/downloads/) រួចដំឡើងវាជាធម្មតា។

### ជំហានទី ២៖ បើកសិទ្ធិដំណើរការស្គ្រីប (Permissions)
1. ប្រើប្រាស់បញ្ជា `cd` ក្នុង Terminal ទៅកាន់ថតកម្មវិធី (ឧទាហរណ៍៖ `cd ~/Desktop/TTS`)។
2. វាយបញ្ជាខាងក្រោមដើម្បីបើកសិទ្ធិដំណើរការស្គ្រីបដំឡើង និងបើកកម្មវិធី៖
   ```bash
   chmod +x setup.sh START_APP.command
   ```

### ជំហានទី ៣៖ ដំណើរការដំឡើង (Setup)
1. នៅក្នុង Terminal វាយបញ្ជាខាងក្រោម រួចចុច Enter៖
   ```bash
   ./setup.sh
   ```
2. រង់ចាំរហូតដល់ដំណើរការដំឡើងបណ្ណាល័យកូដ និងការទាញយកម៉ូដែលសំឡេងត្រូវបានបញ្ចប់ជាស្ថាពរ។

### ជំហានទី ៤៖ បើកដំណើរការកម្មវិធី (Start)
1. អ្នកអាចចុចពីរដង (Double-click) លើឯកសារ `START_APP.command` នៅក្នុង Finder ឬវាយបញ្ជាខាងក្រោមនៅក្នុង Terminal៖
   ```bash
   ./START_APP.command
   ```
2. បើកកម្មវិធីរុករក (Chrome, Safari, ឬ Edge) ហើយចូលទៅកាន់៖ [http://127.0.0.1:8000](http://127.0.0.1:8000)។

## 🔑 របៀបធ្វើឱ្យកម្មវិធីសកម្ម (How to Activate the License)

កម្មវិធីនេះត្រូវបានការពារដោយប្រព័ន្ធសុវត្ថិភាពចាក់សោលើគ្រឿងម៉ាស៊ីន (Hardware ID Lock)។ នៅពេលបើកដំណើរការលើកដំបូង៖

1. កម្មវិធីនឹងបង្ហាញផ្ទាំង **"Activation Required"** (ទាមទារការធ្វើឱ្យសកម្ម)។
2. នៅលើអេក្រង់ អ្នកនឹងឃើញលេខ **Hardware ID (HWID)** របស់អ្នក (ឧទាហរណ៍៖ `THY-A1B2-C3D4-E5F6`)។
3. ចុចប៊ូតុង **"Copy"** ដើម្បីចម្លងលេខកូដសម្គាល់ម៉ាស៊ីននោះ រួចផ្ញើវាទៅកាន់លោក **Mr. THY**។
4. នៅពេលទទួលបាន **License Key** ត្រឡប់មកវិញ សូមយកមកផាស (Paste) ចូលទៅក្នុងប្រអប់ "Enter License Key" រួចចុចប៊ូតុង **"Activate Software"**។
5. កម្មវិធីនឹងដំណើរការ និងដោះសោជូនអ្នកប្រើប្រាស់ភ្លាមៗ!
