# Repository-Specific Rules

## Changelog Guidelines
* **User-Facing Only**: When writing release changelogs in `version.json` or GitHub Release descriptions, ONLY list functional changes, new features, and user-facing improvements (e.g., progress bars, Khmer model, subtitle clean-up buttons).
* **No Technical Details**: Do NOT document any system configuration fixes, dependency changes, compiler modifications (such as Python version updates or Inno Setup changes), or internal system bug fixes in the changelog.
